FREE PUBLISHING (GITHUB PAGES)
1. Create a free account at github.com.
2. Create a new PUBLIC repository named: dinitenoble.github.io (replace with your GitHub username if needed).
3. Upload index.html and the entire assets folder.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch, choose main, and / (root), then Save.
6. Your site will publish at https://YOURUSERNAME.github.io/

You can also upload this folder to any static hosting provider that supports HTML/CSS/JS.
